# SAP ABAP Leave Management System

## Description
This project is developed in SAP ABAP to manage employee leave requests, approval, and reporting.

## Modules
- Leave Request Program
- Leave Approval Program
- ALV Display Report

## Technologies Used
- SAP ABAP
- SE11 (Database Table)
- SE38 (Reports)
- ALV Grid

## Project Flow
Employee → Request Leave → Manager Approval → Status Update → Report Display
